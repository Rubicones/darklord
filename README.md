# Да, Тёмный Властелин! — электронная версия

Электронная версия карточной игры для компании в одной комнате. Две схемы:

- **Одно устройство** (`/local`) — телефон/планшет передают по кругу. Рука автоматически переключается на того, кто сейчас оправдывается. Состояние хранится в `localStorage`.
- **Комната** (`/r/КОД`) — у каждого свой телефон, синхронизация через Supabase Realtime. Можно добавить «общий экран стола» (ноутбук/планшет), который видит всё и ходит за любого.

Приложение не блокирует ходы, а подсказывает: Владыка может давать слово, раздавать карты, снимать Взоры, передавать трон; любое действие отменяется кнопкой «↶».

## Запуск

```bash
npm install
npm run dev            # http://localhost:3000
npm run dev -- -H 0.0.0.0   # чтобы открыть с телефона в той же Wi-Fi сети
```

## Supabase (для комнат)

1. Создайте проект на supabase.com.
2. SQL Editor → вставьте и выполните `supabase/schema.sql`.
3. Скопируйте `.env.example` в `.env.local` и заполните URL и anon/publishable-ключ (Project Settings → API).
4. Перезапустите `npm run dev`.

Как это работает: всё состояние партии — один JSON в строке `rooms.state`. Каждое действие применяется чистым редьюсером (`lib/game/engine.ts`) и записывается с проверкой версии (`update … where version = N`); при конфликте клиент подтягивает свежую версию и повторяет. Изменения приходят на остальные устройства через `postgres_changes`, онлайн-статус — через Presence. Если Realtime недоступен, включается опрос раз в 3 секунды.

> Политики RLS открыты для всех, кто знает код комнаты — это игра «для своих». Руки игроков технически видны в состоянии комнаты.

## Структура

- `lib/cards.ts` — 80 намёков, 37 действий (тип: стрелки / паровоз / оба, наличие черепа), 3 Взора.
- `lib/game/engine.ts` — правила и история отмены.
- `lib/store/` — локальное хранилище и комнаты Supabase.
- `components/game/` — стол, рука, панель Владыки, «Пощадите, Владыка!», финал, правила.
- `public/cards/` — карты, вырезанные из PDF (полный размер и `-s` миниатюры, WebP).
